## Summary

A Claude Code plugin marketplace containing two plugins: **oracle-skills** (13 essential skills from The Great Archive Migration) and **ralph-soulbrews** (self-referential AI development loops). Born from 8 months of daily AI tool building, then ruthless archival: 79 commands → 0 → 12 survivors.

## Key Insight

**The marketplace.json plugin structure**: Plugins declare skills as paths (`./skills/trace`), allowing Claude Code to auto-discover and load them. This is the official plugin format for distribution.
